# Blazemap Frontend

The public web interface for Blazemap, a forest and land fire awareness project focused on Kalimantan, Indonesia.

## Purpose

Provides Home and Contact pages, citizen registration, and separate citizen and government login entry points with email and Google authentication.

## Tech Stack

| Area | Technology |
| --- | --- |
| Application | React 19, TypeScript, Vite 8 |
| Navigation | React Router 7 |
| Styling | Tailwind CSS 4, Radix UI, Lucide |
| Motion | Framer Motion, Lenis |
| Hosting | Railway, nginx |
